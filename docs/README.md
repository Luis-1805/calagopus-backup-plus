> [!TIP]
> In a hurry? The short version: make sure the server's **backup limit** is at least **6**, open the server's
> **Auto-Backups** tab, keep the **GFS compact** template selected and click **Apply template**. You now always have
> the last 3 hourly backups, one weekly and one monthly backup.
